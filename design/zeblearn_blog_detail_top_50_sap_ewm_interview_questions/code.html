SAP Extended Warehouse Management (EWM) interviews at Big-4 and Fortune 500 supply chain practices test far more than theoretical definitions. Hiring managers assess whether you understand live transaction executions, queue troubleshooting, and warehouse order creation rules.

QUESTION 01 OF 50

01. WHAT IS THE CORE DIFFERENCE BETWEEN WAREHOUSE TASK (WT) AND WAREHOUSE ORDER (WO)?

A Warehouse Task is the lowest executable movement instruction (e.g. move SKU-884 from Storage Bin 01-A to Bin 04-B). A Warehouse Order represents a package of Warehouse Tasks grouped together according to Warehouse Order Creation Rules (WOCR) for an individual operator or forklift.

Common Interview Trap

Candidates often confuse Transfer Orders (TO) from legacy WM with Warehouse Orders (WO). In EWM, TO does not exist. A Warehouse Order acts as a work package that binds multiple Warehouse Tasks based on volume, weight, and operator capacity limits.

“If you explain WOCR grouping criteria by volume and weight limits instead of reciting textbook definitions, you instantly separate yourself from 90% of candidates.”
PRO-TIP FOR INTERVIEW

Always reference T-Code /SCWM/MON when asked how you investigate stuck stock movements. Demonstrating familiarity with the Warehouse Management Monitor proves real server experience.

QUESTION 02 OF 50

02. HOW DOES AUTOMATIC WAVE CREATION TRIGGER IN OUTBOUND PROCESSING?

Wave generation groups Outbound Delivery Orders (ODO) into waves based on common criteria like departure schedules, delivery priority, ship-to party, or carrier. This optimizes picking trips and matches shipping stage schedules with dock door availability.

01 // AUTOMATIC EXECUTION

Triggered during delivery creation via condition techniques (/SCWM/WDG - Wave Determination Rules). Condition tables evaluate route and staging dates.

02 // BACKGROUND JOB POLLING

Using report /SCWM/R_WAVE_BATCH scheduled periodically to consolidate non-assigned ODO items before the cutoff time.
